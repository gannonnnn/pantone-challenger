# Pantone Challenger V1.5.2 Release Report

**Release:** V1.5.2 — Temporal and Semantic Integrity  
**Built:** 2026-09-06T20:49:39.251147+00:00  
**Base:** Pantone Challenger V1.5.1 Color Truth

## Purpose

V1.5.1 proved that a displayed HEX existed in decoded source pixels. V1.5.2 addresses the next question: whether that real pixel is current, intentional enough to matter, and eligible to support a cultural-trend claim.

## Implemented safeguards

- Rejects source records dated after the requested cultural date.
- Requires current dates for discovery, creation, marketplace, and art events.
- Treats undated historical art, permanent collections, general catalogs, and stale discovery items as context only.
- Treats unchanged benchmark creative as baseline/mainstream evidence rather than emergence.
- Allows an undated benchmark region to become current distribution evidence only after its fingerprint changes from a prior accepted day.
- Stores first-seen, last-seen, and last-changed fingerprints at source-region level.
- Verifies total matched-color area and the largest connected patch in each supporting creative region.
- Uses stricter substance and cluster-width limits for muted, low-chroma colors.
- Builds a second, integrity-audited color ranking from only current and substantial local swatches.
- Blocks the day if the pipeline winner and audited winner disagree instead of silently replacing the result.
- Evaluates co-Challengers only after temporal, semantic, chromatic, source, and domain eligibility.
- Replaces emergence language with calibration language until seven prior valid days exist.
- Reports source balance by domain, signal stage, scale class, panel, and sector.
- Quarantines social assets whenever the integrity gate blocks a result.

## Known limits

- Connected-area checks reduce incidental UI, skin-sized, prop-sized, and background fragments, but they do not claim to understand artistic intent. Human review remains appropriate during calibration.
- Some sources do not expose reliable publication dates. Those sources can build a benchmark after repeated fingerprints, but cannot prove first-day emergence.
- V1.5.2 is intentionally a gate, not a silent replacement scorer. If filtering changes the leader, the day is blocked for a clean recalculation in a future scoring release.
- Marketplace/API event quality still depends on the provider's timestamps and source metadata.
