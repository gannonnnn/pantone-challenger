# V1.5.2 CI and Tie-Eligibility Hotfix

This hotfix corrects three packaging defects in the initial V1.5.2 upgrade:

1. Tie evaluation trusted an unset `CandidateInfo.neutral` field instead of deriving neutrality from the candidate HEX.
2. `config/settings.yml` and pipeline fallbacks still declared methodology V1.5.1, causing release validation to fail.
3. The CI workflow reintroduced duplicate branch checks and a broader lint policy than the repository had already adopted.

No scoring threshold, temporal rule, semantic rule, color-provenance rule, source registry, or social rendering behavior is loosened.
