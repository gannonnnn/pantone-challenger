# Temporal and Semantic Integrity — V1.5.2

Pantone Challenger distinguishes a real source color from a current cultural signal.

## Daily evidence roles

- **Eligible current:** tied to the requested cultural date or an allowed event window and supported by a meaningful connected color area.
- **Calibration only:** newly observed but undated benchmark creative; useful while history warms, not proof of emergence.
- **Baseline only:** static or stale benchmark creative; useful for normal-use and mainstream comparisons.
- **Context only:** undated or stale historical art, catalogs, permanent collections, and discovery material without a dated cultural event.
- **Rejected:** future-dated, overlay-like, fragmented, or otherwise untrustworthy evidence.

## Temporal rules

Future-dated evidence is rejected. Newly published, listed, created, or promoted discovery material must carry a date within its configured current window. Exhibitions receive a longer window. Historical art is not treated as newly created merely because it was digitized or surfaced by an API.

## Semantic rules

A source must contain a meaningful connected area close to its claimed local swatch. Scattered buttons, text, skin-sized fragments, tiny props, and anti-aliased interface accents do not qualify merely because the exact pixel exists. Muted low-chroma clusters use tighter coherence and connected-area thresholds.

## Calibration language

Before seven prior valid days, the system reports a provisional calibration score, never a trend-emergence score. Static observations can build a baseline without becoming a public Challenger.

## Safe failure

The postflight integrity gate never invents a replacement winner. It can preserve a valid result, downgrade it to review or baseline only, or block it and quarantine social assets.
