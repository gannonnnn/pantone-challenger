# Pantone Challenger V1.5.3 Release Report

**Release:** V1.5.3 — Bounded Runtime and Shared Browser

**Purpose:** Prevent a few slow sources from producing hour-long daily jobs while preserving every existing evidence and color-integrity safeguard.

## Incident addressed

A full Daily Challenger run remained in the `generate` job for more than 50 minutes with no source-level progress. The V1.5.2 collector launched a separate Chromium process for each webpage source, allowed up to two URLs and many candidate screenshots per source, and had no source-level wall-clock cutoff or useful heartbeat.

## Repairs

- One Chromium process per webpage batch instead of one per source.
- Six concurrent isolated source contexts.
- 55-second total webpage-source budget.
- 45-second API/feed-source budget.
- 12-second individual HTTP request limit.
- 20-minute browser collection budget.
- 28-minute measurement-command backstop and 35-minute GitHub job limit.
- One optional fallback URL per source.
- Six candidate screenshot attempts and three accepted regions per source.
- Overlap removal before screenshots.
- Faster browser-side candidate discovery.
- Font, media, and common tracker blocking.
- Source-by-source progress and 20-second heartbeats.
- Durable incremental runtime diagnostics.
- Failed-run artifact upload before the workflow exits red.
- Bounded weekly source-health workflow.

## Preserved controls

The release does not weaken:

- exact source-pixel color provenance;
- connected-area and spatial-coverage checks;
- neutral and structural-background handling;
- temporal and semantic integrity;
- dated-art and dated-feed rules;
- duplicate campaign reduction;
- one-source voting and balancing;
- house-color and emergence logic;
- tie eligibility;
- runner-up distinctness;
- public image sizing and rendering validation;
- logo attribution policy;
- calibration and publication states;
- recurrence and year-end reporting.

## Validation completed

- 65 automated tests passed.
- Runtime scheduler test confirms one browser launch for a batch and graceful timeout of a simulated slow source.
- Pipeline test confirms all webpage sources are sent through one browser batch.
- Runtime ledger test confirms incremental JSONL and atomic summary output.
- Workflow tests confirm the 28-minute command backstop, 35-minute job limit, unbuffered logs, cancellation of duplicate runs, and failed-run artifact preservation.
- The configured 58-source panel has a theoretical browser-wave ceiling of 550 seconds under the 55-second/6-worker controls, inside the 1,200-second collection budget.
- Python compilation passed.
- Temporal/semantic validation passed.
- Release validation passed.

## Live validation still required

This environment cannot reproduce the public internet and GitHub-hosted runner exactly. The first live run after merging V1.5.3 remains a calibration test. Its runtime ledger and source results should be reviewed before scheduled operation is enabled.
