# Social account and historical site

## Social role

Instagram is the gallery. Bluesky can function as the daily logbook. GitHub Pages is the permanent evidence and history layer linked from the profile.

Suggested bio:

> One measured color signal from yesterday's visual culture. Art, fashion, marketplaces, campaigns, materials, entertainment, and independent work. Open methodology. Not affiliated with Pantone.

## Daily package

A qualified daily package contains:

1. Main Challenger or Co-Challenger card.
2. Full-screen color reveal.
3. Traceable source evidence with local swatches.
4. Why the color rose.
5. Distinct runners-up.
6. Domain, stage, scale, and panel map.
7. Undercurrent, mainstream leader, and palette-pair context.
8. Caption and alt text.

Calibration graphics are clearly marked not for posting. Baseline-only days do not create a public color claim.

## Historical page

`challenger build-site` creates a static archive with:

- color calendar;
- daily detail pages;
- traceable source attribution;
- machine-readable JSON feed;
- methodology page;
- annual summaries and color grids.

Enable the repository variable `ENABLE_PAGES=true` only after the repository is public and GitHub Pages is configured to use GitHub Actions.
