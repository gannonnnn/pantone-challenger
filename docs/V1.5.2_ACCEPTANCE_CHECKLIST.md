# V1.5.2 Acceptance Checklist

Before merging the repair pull request:

- [ ] CI passes on the repair branch.
- [ ] `daily.yml` contains the temporal and semantic postflight step.
- [ ] Future-dated evidence is rejected in tests.
- [ ] Capture/run dates do not masquerade as publication dates.
- [ ] Undated historical art is context-only.
- [ ] Unchanged benchmark creative is baseline-only.
- [ ] Changed benchmark creative is current only after a prior fingerprint exists.
- [ ] Sparse or fragmented local color support is excluded.
- [ ] Muted candidates use the tighter cluster-diameter limit.
- [ ] Ties are calculated after eligibility filtering.
- [ ] A 0/7 baseline result contains no emergence claim.
- [ ] Blocked results contain no public social assets in the archive.
- [ ] Private artifacts include `temporal-semantic-integrity.json`, `temporal-ledger.json`, and `integrity-summary.md`.

Before accepting calibration day one:

- [ ] The source date belongs to the requested cultural date or allowed event window.
- [ ] Every credited local swatch occupies a meaningful connected region.
- [ ] The pipeline candidate matches the integrity-audited candidate.
- [ ] Domain, signal-stage, scale, and panel counts are visible.
- [ ] The result is labeled calibration, review-only, baseline-only, or blocked as appropriate.
